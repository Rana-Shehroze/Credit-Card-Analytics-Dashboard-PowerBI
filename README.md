# 💳 Credit Card Analytics Dashboard (Power BI)

This Power BI project analyzes a fictional credit card dataset to uncover business and customer insights.

## 📊 Key Dashboards

### 1. Credit Card Transaction Report
- Total Revenue, Interest, Amount, and Count KPIs
- Revenue by card type, job, education, and spending category
- Quarterly transaction trends
- Card method usage breakdown (Swipe, Chip, Online)

### 2. Credit Card Customer Report
- Income and average age KPIs
- Gender-wise revenue trends over time
- Revenue by car ownership, house ownership
- Revenue by card categories and customer segments

## 🛠 Tools Used
- Power BI Desktop
- DAX (Data Analysis Expressions)
- Power Query Editor
- Data modeling and transformations

## 🧠 Skills Demonstrated
- Business storytelling through visuals
- KPI design and layout
- Conditional logic with DAX
- Customer segmentation and behavior insights
